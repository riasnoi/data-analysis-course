## Что такое HMDA

HMDA — Home Mortgage Disclosure Act, закон США о раскрытии ипотечных данных. Здесь мы используем публичные записи, опубликованные CFPB/FFIEC в рамках этой отчётности: покупка жилья, District of Columbia (Вашингтон), 2023 год.

- action_taken = 1: кредит выдан.
- action_taken = 2: заявка одобрена, предложение не принято.
- action_taken = 3: отказ.

На практике определяем одобрение как исходы 1 и 2, выдачу — как исход 1. Знаменатель основного расчёта — записи с исходами 1–3. Сначала объясните определение, затем считайте.

| Файл | Для чего нужен |
|---|---|
| data/reading_example.csv | 6 намеренно подобранных реальных строк для ручного разбора |
| data/decisions.csv | 6 830 записей, основной набор практики |
| data/hmda_2023_dc_raw.csv | 8 575 записей с исходами 1–5, дополнительное задание |
| data/card.md | Происхождение, словарь полей, единицы и ограничения |
| data/manifest.json | Параметры получения и контрольные суммы снимка |
| data/*.json, кроме manifest | Сохранённые ответы API для прослеживаемости; вручную открывать на первой практике не требуется |

Данные уже включены. После установки окружения интернет для выполнения практики не нужен. Сумма кредита указана в USD, доход — в тысячах USD в год. LEI обозначает организацию. Эти данные не показывают последующие дефолты; одна запись не обязательно соответствует одному уникальному человеку. Подобранные шесть строк не являются случайной выборкой.

## Что сдавать

Для практики: заполненный work/notebook.ipynb и отчёт work/README.md с ответами A–G. Для домашней: work/homework.ipynb с решениями H1–H2 и work/homework.md с результатами и объяснениями H1–H3. Дополнительные задания выполняются по желанию.

Перед сдачей каждого ноутбука выполните **Restart Kernel → Run All**, сохраните код и выводы. Все выполненные вами задания должны запускаться сверху вниз без ошибок. Пустые ячейки необязательной части домашней допустимы. Данные не изменяйте.

Практика и базовая домашняя оцениваются отдельно по 10-балльным рубрикам в своих инструкциях. Способ передачи работ объявляет преподаватель; публиковать решения в общий репозиторий курса не нужно.

## Сохранение в Git

Команды выполняются в терминале из корня **своей копии репозитория курса**. После clone/fork история Git уже существует. Только для распакованного ZIP сначала выполните git init один раз.

После практики:

```bash
git status
git add lessons/01-introduction/work/notebook.ipynb lessons/01-introduction/work/README.md
git commit -m "Выполнена первая практика HMDA"
```

После домашней:

```bash
git status
git add lessons/01-introduction/work/homework.ipynb lessons/01-introduction/work/homework.md
git commit -m "Выполнена домашняя работа 1"
```

При запросе имени/email настройте собственные значения локально в этом репозитории. Виртуальная среда и временные файлы уже исключены через .gitignore.
