# Домашняя работа 1 — доли исходов HMDA

Откройте отдельный ноутбук домашней работы и выполните его сверху вниз. Он сам загружает данные и не использует переменные из практики. В ноутбуке оставлены заголовки и код; письменные ответы записывайте в отдельный отчёт домашней работы рядом с ним.

## Данные и начало работы

Базовые задания используют decisions.csv — 6 830 опубликованных записей о покупке жилья в Вашингтоне за 2023 год с исходами 1–3. Код 1 означает выдачу, код 2 — одобрение без принятия предложения, код 3 — отказ. [Словарь полей](../data/card.md) тот же, что на практике.

Выполните подготовку и загрузку. home_decisions — таблица, home_outcomes — столбец исходов, home_n — общее количество записей. Проверьте показанные столбцы, размер и частоты. Общее количество для всех базовых долей — home_n.

Для работы достаточно изученных read_csv, выбора столбцов, eq, isin, sum, len и assert. Доля равна количеству подходящих записей, делённому на общее количество. Для процента умножьте долю на сто. Сначала считайте по исходным числам, затем форматируйте вывод.

## H1. Доля отказов

Получите home_denied — количество записей с кодом 3, и home_denial_rate — их долю. Отдельно покажите условие, числитель, знаменатель и процент.

Затем получите home_approved — количество одобрений с кодами 1 и 2. Проверьте через assert, что home_denied + home_approved равно home_n, а доля отказов находится от 0 до 1.

В отчёте H1 сформулируйте определение и вывод: среди каких записей посчитана доля и что означает результат.

## H2. Одобрение без принятия предложения

Получите home_not_accepted — количество записей с кодом 2, и home_not_accepted_rate — их долю среди тех же home_n записей. Покажите счётчики и процент.

В этом же ноутбуке самостоятельно получите home_issued — количество выдач. Проверьте равенство home_approved - home_issued == home_not_accepted. Для этой проверки используйте исходные количества, чтобы округление процентов не влияло на результат.

Посчитайте разность долей одобрений и выдач и выразите её в процентных пунктах. В отчёте H2 объясните связь этой разности с исходом 2. Приведите оба расчёта, показывающих связь.

## H3. Объяснение инструментов

В отчёте H3 своими словами объясните три различия: Series и DataFrame; nrows и head; метод и атрибут. Для каждого приведите короткий пример из своей работы. Выберите один использованный метод в [списке документации](../lecture/references.md), добавьте ссылку и назовите свойство или параметр, который уточнили по документации.

Отдельная кодовая ячейка для письменного ответа H3 не нужна: текст находится в отчёте, ноутбук содержит только код и заголовки.

## H+1. Другой набор записей — по желанию

Выполните предоставленную загрузку hmda_2023_dc_raw.csv. Это более широкий снимок: кроме кодов 1–3 есть код 4 — заявка отозвана, и код 5 — рассмотрение закрыто из-за неполноты документов. Переменная raw содержит таблицу, raw_outcomes — исходы, raw_n — количество её записей.

Самостоятельно посчитайте долю выдач среди всех строк raw. Отдельно посчитайте долю выдач среди home_decisions. Покажите для каждой числитель, знаменатель и процент. Через assert проверьте совпадение количества выдач в этих двух файлах.

В отчёте H+1 объясните, какие записи добавились в общее количество, и дайте каждой доле полное название. Для выполнения достаточно двух загруженных таблиц; сложная фильтрация не требуется.

## H+2. Тип сравниваемого значения — по желанию

Выполните загрузку text_example: это те же шесть строк reading_example.csv, но action_taken прочитан как string. Сравните результаты eq(1) и eq("1") для этого столбца. Покажите сначала логические значения, затем количество True.

В отчёте H+2 объясните разницу результатов и запишите, какое сравнение отвечает типу прочитанных значений. Работа выполняется в отдельной переменной text_example и не меняет home_decisions.
