# Домашняя работа 4 Сохранённый справочник и покрытие JOIN

Откройте [ноутбук ДЗ](../work/homework.ipynb). Он загружает снимок и определяет функцию collect_pages. Практика перед ним не нужна. Обязательная работа выполняется без сети. Запишите письменные ответы в [отчёт ДЗ](../work/homework.md). Ориентир: 35–45 минут на базу и 35–50 минут на дополнительные проверки.

## Данные и подготовка

[Поля и происхождение](../data/card.md). manifest содержит выбранные LEI и метаданные страниц, cache связывает адреса с сохранёнными JSON. Функция cached_loader получает страницу из cache; collect_pages обходит ссылки и проверяет завершение. Эти вспомогательные функции предоставлены, переписывать их не требуется.

## H1 Полный справочник

Получите home_records через collect_pages. Преобразуйте записи в таблицу, выберите id, юридическое имя и страну адреса. Переименуйте поля в lei, legal_name_current, legal_country_current, приведите lei к string. Проверьте известность, уникальность и точное совпадение полученных кодов с selected_lei. В отчёте назовите смысл строки и дату сведений.

## H2 Пакет для повторного запуска

Создайте ../results/homework/raw. Сверьте SHA-256 каждой исходной страницы, затем скопируйте её байты в эту папку. Сохраните рядом исходный manifest. Таблицу запишите в ../results/homework/lookup.csv, прочитайте её повторно с lei как string и сравните через assert_frame_equal. Для вложенных папок используйте mkdir(parents=True, exist_ok=True): parents создаёт недостающие уровни пути. В отчёте объясните назначение исходников, manifest и преобразованной таблицы.

## H3 Два вида покрытия

Выполните left many_to_one JOIN decisions с home_lookup. Проверьте сохранность исходных полей. По _merge найдите количество совпавших ипотечных записей и число различных совпавших lei. Посчитайте покрытие по записям и по организациям, явно выводя оба числителя и знаменателя. Сохраните coverage.json в папку homework с четырьмя счётчиками и двумя долями. В отчёте объясните разницу единиц и частичный охват, уточните своё предложение проекта после обратной связи.

## H+ Контрпримеры по желанию

На отдельных deepcopy(cache) проверьте пять случаев: next ведёт на уже открытую страницу; max_pages слишком мал; на разных страницах повторён id; total изменился; data отсутствует. Для каждой копии вызовите collect_pages, покажите ожидаемый ValueError и убедитесь, что исходный cache сохранился. lambda url: changed[url] передаёт функции способ загрузки из изменённой копии, не меняя cached_loader.
