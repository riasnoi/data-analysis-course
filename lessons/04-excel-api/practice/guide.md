# P05 Описание проекта

Разбейтесь на пары. Выберите один аналитический вопрос и подготовьте одно описание проекта на двоих. Темы можно взять из [методички по проекту](project_handbook.pdf). Общий набор для старта — [decisions.csv](../data/decisions.csv) с ипотечными записями HMDA за 2023 год по округу Колумбия. Значения полей указаны в [карточке данных](../../01-introduction/data/card.md).

1. Сформулируйте вопрос так, чтобы по имеющимся полям можно было выполнить конкретное сравнение. Назовите, кому и для чего может пригодиться ответ.
2. Заполните [шаблон описания](proposal_template.md). Укажите, какие строки и поля возьмёте, что будете считать, какое ограничение уже видно и с чего начнёте на следующей практике.
3. Покажите черновик соседней паре. Попросите проверить, хватает ли полей для ответа и понятно ли, как считать показатель. Уточните описание после обсуждения.

**Что сдать.** Один заполненный `project_proposal.md` на пару с именами обоих участников.
