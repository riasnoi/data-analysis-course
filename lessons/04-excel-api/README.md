# Занятие 4. Получение данных из Excel и API

На лекции разберём листы Excel, вложенные поля JSON, HTTP-ответ и обход нескольких страниц API. На практике P05 вы сформулируете свой проект в паре. В ДЗ вы соберёте справочник из сохранённых ответов GLEIF и измерите покрытие по ипотечным записям и по организациям.

## Лекция

- Слайды в [PDF](lecture/lecture_slides.pdf) и [PowerPoint](lecture/lecture_slides.pptx).
- Конспект в [Markdown](lecture/lecture_notes.md) и [PDF](lecture/lecture_notes.pdf).
- [Демонстрационный ноутбук](lecture/lecture_demo.ipynb) и [вопросы для повторения](lecture/lecture_questions.md).

## Практика P05

Разбейтесь на пары и сдайте одно описание проекта на двоих. В [условиях P05](practice/guide.md) указан порядок работы. Заполните [шаблон описания](practice/proposal_template.md). Примеры вопросов, роли и этапы проекта собраны в [методичке PDF](practice/project_handbook.pdf).

## Домашняя работа

Откройте [условия](practice/homework.md) и [отдельный ноутбук](work/homework.ipynb). Выполните H1–H3, заполните [отчёт](work/homework.md) и уточните в нём вопрос проекта с учётом обратной связи. H+ выполняется по желанию.

Для повторения доступны [учебные примеры по Excel и API](practice/excel_api_examples.md) и [ноутбук с примерами](work/notebook.ipynb).

## Запуск ноутбуков и сдача

Обновите зависимости из requirements.txt по [инструкции курса](../../README.md#подготовка-окружения). Открывайте ноутбуки в их папках lecture/ или work/ и выбирайте ядро «HMDA — занятие 1». Все файлы для обязательной работы находятся в data/. Поля, источники и ограничения описаны в [карточке данных](data/card.md).

Перед сдачей ДЗ выполните Restart Kernel → Run All. Сохраните файлы в своей копии репозитория.

| Работа | Файлы для сдачи |
|---|---|
| Практика P05 | Один файл project_proposal.md с именами обоих участников |
| Домашняя работа | work/homework.ipynb, work/homework.md с уточнённым вопросом проекта, пакет results/homework/ целиком |
