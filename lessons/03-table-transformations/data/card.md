# Данные практики 3

Файлы подготовлены из сохранённых ответов CFPB/FFIEC HMDA за 2023 год по округу Колумбия. Подробности об отборе и полях приведены в [карточке исходных данных](../../01-introduction/data/card.md). Контрольные суммы CSV указаны в [manifest.json](manifest.json).

organizations.csv — 470 реальных организаций из Filers API, ключ (lei, activity_year). organization_name — опубликованное имя; source_count — count исходного API, охватывающий другой отбор и не являющийся знаменателем наших долей. period переименован в activity_year для явного соединения. 314 организаций присутствуют в decisions.csv, 156 не имеют записей в нашем фильтре; это не неизвестные/невалидные организации.

outcome_counts.csv — 500 наблюдаемых комбинаций (lei, activity_year, action_taken), n — число записей среди выбранных исходов 1/2/3. Всего n=6830. Уникальный составной ключ. outcome_wide.csv — те же счётчики в широкой форме: 314 строк организаций, поля issued/approved_not_accepted/denied. Отсутствующий в полном сохранённом фильтре исход имеет число 0; это допустимое структурное отсутствие счётчика, не заполнение неизвестного дохода.

Для JOIN основной источник — неизменённый decisions.csv: 6830 строк. Для демонстрации ошибок в ноутбуке явно создаются частичный справочник и копия с повторной доставкой строки; эти изменения не приписываются официальному API.

Словарь: lei — string/LEI организации; activity_year — отчётный год int; source_row — технический номер источника (не ID клиента); action_taken — код исхода; organization_name — string, не ключ; source_count — число записей более широкого источника; n/issued/approved_not_accepted/denied — неотрицательные целые числа записей текущего аналитического слоя.

Получение для занятия: прочитайте локальные CSV. Проверки: справа ключ уникален и известен; слева source_row уникален; many-to-one сохраняет 6830 строк, unmatched=0; объединённые имена не меняют исходы и суммы. После reshape сумма счётчиков остаётся 6830. Средние долей организаций и доля всех записей отвечают разным вопросам.
