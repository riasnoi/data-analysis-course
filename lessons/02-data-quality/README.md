# Занятие 2 Качество данных

Проверяем знакомый набор HMDA и отдельную учебную копию с дефектами. Учимся различать пропуски, ошибки формата и необычные значения, разбирать повторную доставку и сохранять проверенный результат. В плане курса это лекция L02 и практика P03; между первым блоком и ними предусмотрена отдельная практика P02 по pandas.

## Что открывать по порядку

1. На лекции — [слайды](lecture/lecture_slides.pdf). Для повторения: [конспект](lecture/lecture_notes.md), [PDF](lecture/lecture_notes.pdf), [вопросы](lecture/lecture_questions.md). [Демонстрационный ноутбук](lecture/lecture_demo.ipynb) содержит разобранные примеры.
2. На практике — [методичка](practice/guide.md), [рабочий ноутбук](work/notebook.ipynb) и [шаблон отчёта](work/README.md). Задания A–E выполняются сверху вниз.
3. Для разбора после выполнения — [заполненная практика](practice/practice_solutions.ipynb).
4. Домашняя — [отдельный ноутбук](work/homework.ipynb), [условия](practice/homework.md), [отчёт](work/homework.md). База H1–H3; H+1–H+2 по желанию.

## Данные и запуск

[Словарь и источник](data/card.md), [описание учебной копии](data/training_card.md). Исходные файлы уже включены. Окружение то же, что в [первом занятии](../01-introduction/README.md#запуск): Python и pandas 2.2.2. Запустите JupyterLab из корня репозитория и откройте ноутбук в его папке; ядро «HMDA — занятие 1» подходит обоим занятиям.

Все ноутбуки читают ../data относительно своей папки. Практика и домашняя загружают вход независимо. Результаты практики сохраняются в results/ внутри этого занятия; папка создаётся кодом. Исходные CSV сохраняйте без изменений.

## Сдача и оценивание

Практика: work/notebook.ipynb, work/README.md и results/clean.csv, results/quarantine.csv, results/quality_report.json. Домашняя: work/homework.ipynb и work/homework.md. Перед сдачей Restart Kernel → Run All.

Каждая базовая работа оценивается отдельно по 10 баллов: правила 2, основной результат 3, проверки 2, вывод 1, воспроизводимость и передача 2. Подробности в методичках. Необязательные задания не снижают базовую оценку.

После домашней:

