# Данные второго занятия

Оригинал decisions.csv совпадает с файлом первого занятия: публичные HMDA, покупка жилья, Вашингтон, 2023 год, исходы 1–3. [Полное происхождение, словарь и ограничения](../../01-introduction/data/card.md). [Описание учебной копии](training_card.md).

| Поле | Значение |
|---|---|
| source_row | Номер исходной строки сохранённого снимка |
| activity_year | Отчётный год |
| lei | Код организации |
| county_code | Территория, текстовый код |
| action_taken | 1 — выдача, 2 — одобрение без принятия, 3 — отказ |
| loan_amount | Сумма кредита, USD |
| income | Доход за год, тыс. USD |

Контрольные суммы файлов находятся в manifest.json. Файлы включены в репозиторий; для занятия сеть не нужна.
