# Учебная копия выгрузки

training_export.csv создан детерминированно из реального decisions.csv. Для упражнения изменены несколько текстовых значений, формат кода территории и повторно доставлены две исходные строки. Новые заявки не создавались. Это намеренно повреждённая учебная копия, которую разбираем на второй лекции.

Поля имеют тот же [словарь](card.md). В начале все значения читаются как string, чтобы видеть исходный текст. Неизвестные значения остаются пропусками. Оригинальный decisions.csv сохранён для сравнения и не изменяется.

Карантин должен сохранять исходные значения и причину исключения. Правила подготовки и определения показателей записываются в отчёте вместе с фактическими счётчиками. Контрольные суммы — в manifest.json.
