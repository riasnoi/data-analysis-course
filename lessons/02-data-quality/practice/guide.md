## Данные и поля

Оригинальный decisions.csv содержит опубликованные ипотечные записи о покупке жилья в Вашингтоне за 2023 год. training_export.csv — отдельная учебная копия с намеренно внесёнными дефектами. На лекции показаны оба файла. [Карточка учебной копии](../data/training_card.md) содержит происхождение; [общая карточка](../data/card.md) — источник HMDA и ограничения.

| Поле | Значение |
|---|---|
| source_row | Технический номер строки исходного снимка |
| activity_year | Отчётный год, здесь 2023 |
| lei | Код организации, повторяется в разных записях |
| county_code | Код территории, ожидаем текст 11001 |
| action_taken | 1 — выдача, 2 — одобрение без принятия, 3 — отказ |
| loan_amount | Сумма кредита в USD |
| income | Доход за год в тысячах USD, может отсутствовать |

Одобрения считаем по кодам 1 и 2. В знаменателе — все строки явно названной таблицы с исходами 1–3. Ошибка формата означает, что текст не удалось прочитать числом; пропуск означает отсутствие известного значения. Необычная большая сумма требует просмотра по смыслу поля.
## Инструменты

copy(deep=True) создаёт отдельную таблицу. isna/notna возвращают логические отметки отсутствия/наличия значения; sum считает True. loc выбирает строки по маске и столбцы по именам. & требует оба условия в каждой строке, | — хотя бы одно, ~ меняет True и False местами.

pd.to_numeric(series, errors="coerce") преобразует текст в числа; нераспознанный текст становится пропуском. Новая ошибка — исходное notna и полученное isna одновременно. str.strip убирает внешние пробелы. isin проверяет допустимые коды. duplicated отмечает повторные вхождения; keep=False отмечает всю группу совпадений. drop_duplicates без subset сравнивает все столбцы, с subset — только указанные. is_unique сообщает об отсутствии повторов.

В функции reason — текстовая Series с метками строк. Присваивание через loc меняет выбранные элементы; += дописывает причину к тексту. out.index связывает преобразованные строки с исходными; source.loc[out.index[invalid]] возвращает их исходные значения для карантина. int превращает счётчик pandas в обычное число Python для JSON. assert останавливает код при ложном условии; all требует выполнения условия во всех строках. assert_frame_equal сравнивает значения, типы и индексы двух таблиц.

[Документация pandas](https://pandas.pydata.org/pandas-docs/version/2.2/). Порядок объяснения методов и полные примеры находятся в конспекте второй лекции.
