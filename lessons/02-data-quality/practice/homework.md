# Домашняя работа 2 Качество данных

Работа выполняется в [отдельном ноутбуке](../work/homework.ipynb). Он самостоятельно загружает данные; запускать практику перед ним не нужно. Письменные ответы находятся в [шаблоне отчёта](../work/homework.md) рядом. База H1–H3, дополнительная часть H+1–H+2 необязательна.

## Данные и поля

Оригинальный decisions.csv содержит опубликованные ипотечные записи о покупке жилья в Вашингтоне за 2023 год. training_export.csv — отдельная учебная копия с намеренно внесёнными дефектами. На лекции показаны оба файла. [Карточка учебной копии](../data/training_card.md) содержит происхождение; [общая карточка](../data/card.md) — источник HMDA и ограничения.

| Поле | Значение |
|---|---|
| source_row | Технический номер строки исходного снимка |
| activity_year | Отчётный год, здесь 2023 |
| lei | Код организации, повторяется в разных записях |
| county_code | Код территории, ожидаем текст 11001 |
| action_taken | 1 — выдача, 2 — одобрение без принятия, 3 — отказ |
| loan_amount | Сумма кредита в USD |
| income | Доход за год в тысячах USD, может отсутствовать |

Одобрения считаем по кодам 1 и 2. В знаменателе — все строки явно названной таблицы с исходами 1–3. Ошибка формата означает, что текст не удалось прочитать числом; пропуск означает отсутствие известного значения. Необычная большая сумма требует просмотра по смыслу поля.
## H1 Функция по плану

Выполните подготовку и загрузку. Самостоятельно напишите clean_export(source), возвращающую clean, quarantine, audit. План: копия входа; проверка конфликтующих версий известного source_row; исключение одинаковой повторной доставки; внешние пробелы территории; числовые преобразования с подсчётом новых ошибок; маска обязательных правил; подготовленный слой и карантин с исходными значениями и reason; журнал и баланс.

Обязательные правила те же: известный номер, исходы 1–3, известная положительная сумма, территория 11001. income может отсутствовать. Журнал содержит input, replays, clean, quarantine, parse_errors. Используйте разобранные инструменты; план и [методичка практики](guide.md) доступны для повторения.

## H2 Год и известный доход

Вызовите свою функцию на export. Проверьте, что во всех подготовленных строках activity_year — строка "2023". Выведите общее количество, количество известных и неизвестных income, средний известный доход и его единицу. Проверьте баланс и сохранность входа. В отчёте объясните, по каким значениям считается среднее и почему неизвестный доход не заменён нулём.

## H3 Проверка с нарушенным годом

Создайте wrong_year = export.copy(deep=True), измените activity_year только первой строки на "2022". Вычислите year_ok через eq("2023").fillna(False).all() и убедитесь, что проверка обнаружила нарушение. fillna(False) здесь считает неизвестный результат проверки непрохождением правила; исходный столбец эта операция не меняет. Проверьте, что export сохранился.

В отчёте различите исходный пропуск, ошибку преобразования и необычно большую числовую сумму. Для каждого случая назовите реакцию и покажите пример из занятия.

## H+1 Конфликт доставки

В отдельной копии измените loan_amount у последней строки, которая является повторной доставкой. Убедитесь, что ваша функция останавливается при двух разных версиях одного известного source_row. try/except позволяет поймать ожидаемый AssertionError; если исключения нет, else должен сообщить об ошибке проверки. В отчёте объясните, почему нельзя просто оставить первую версию.

## H+2 Совпадение опубликованных значений

На оригинальном decisions сравните число строк и сумму loan_amount до и после drop_duplicates по всем полям, кроме source_row. Покажите разницу. В отчёте объясните, какой информации не хватает для признания таких совпадений одной заявкой.
