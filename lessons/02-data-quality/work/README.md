## A. Источник и правила

Файлы, назначение строки, поля и правила проверки:

* **Файлы:** `training_export.csv` (сырые данные с дефектами и повторами), `decisions.csv` (эталонная выгрузка).
* **Назначение строки:** Отдельная заявка на получение ипотечного кредита (loan application).
* **Поля:** `source_row` (первичный идентификатор строки), `activity_year`, `lei`, `county_code`, `action_taken`, `loan_amount`, `income`.
* **Правила проверки:** Значение `source_row` должно быть уникальным; код округа `county_code` строго равен `"11001"`; статус решения `action_taken` принимает только значения из множества `[1, 2, 3]`; сумма займа `loan_amount` должна являться положительным числом больше нуля.

## B. Доход

Исходные пропуски, новые ошибки, итоговые пропуски и разница между ними:

* **Исходные пропуски (NaN/NULL):** 342 записи.
* **Новые ошибки парсинга:** 1 запись (строка `source_row = 5`, текстовое значение `"BAD"`).
* **Итоговые пропуски:** 343 записи.
* **Разница:** Обусловлена принудительным приведением типов через `pd.to_numeric(..., errors="coerce")`, в результате которого некорректный текстовый маркер `"BAD"` был трансформирован в `NaN`.

## C. Карантин и баланс

Числа баланса, спорные source_row, причины исключений и политика income:

* **Баланс:** 6832 (всего на входе) = 6828 (чистые) + 2 (карантин) + 2 (повторные дубликаты `replays`).
* **Спорные строки:** 
  * `source_row = 2`: значение суммы кредита `loan_amount = "oops"`;
  * `source_row = 3`: недопустимый код статуса `action_taken = 88`.
* **Причины исключений:** Метка `invalid_loan_amount;` (нечисловое значение суммы займа) и метка `invalid_action_taken;` (код исхода вне регламентированного перечня 1, 2, 3).
* **Политика по полю income:** Отсутствие сведений о доходе не является основанием для отбраковки заявки на этапе пайплайна очистки, поэтому строки с `NaN` в поле `income` сохраняются в чистом датасете.

## D. Проверки

Утверждения, результат и смысл каждой проверки:

* `assert_frame_equal(result, again)`: Проверка детерминированности функции очистки при повторном запуске.
* `assert_frame_equal(export, raw_copy)`: Проверка иммутабельности (исходный датафрейм не мутирует в процессе обработки).
* `assert result["source_row"].is_unique`: Подтверждение уникальности первичного ключа после дедупликации.
* `assert result["action_taken"].isin([1, 2, 3]).all()`: Гарантия отсутствия недопустимых кодов решений.
* `assert result["loan_amount"].gt(0).all()`: Проверка строгой положительности всех одобренных сумм кредита.
* `assert len(export) == len(result) + len(rejected) + audit["replays"]`: Закон сохранения записей (полная трассируемость строк).
* `assert rejected["reason"].ne("").all()`: Каждая запись в карантине снабжена документированной причиной отбраковки.
