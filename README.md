# Основы анализа данных

Студенческий репозиторий курса. Материалы публикуются постепенно, по мере появления занятий в расписании. В таблице ниже перечислены доступные занятия; даты объявляет преподаватель.

## Опубликованные занятия

| Блок | Лекция | Практика | Материалы |
|---|---|---|---|
| 01 | Введение и табличные вычисления, 90 минут | Первый воспроизводимый анализ HMDA, 90 минут | [Открыть занятие](lessons/01-introduction/README.md) |
| 02 | Качество данных, 90 минут | Проверка и очистка учебной выгрузки, 90 минут | [Открыть занятие](lessons/02-data-quality/README.md) |

Начните со страницы занятия: она объясняет, какие файлы открывать и что сдавать. Отсутствие следующего блока означает, что его материалы ещё не опубликованы.

## Как пользоваться репозиторием

1. Получите свою копию: fork и clone либо Download ZIP → распаковать. Для сохранения решений в Git удобнее fork и clone.
2. Один раз подготовьте окружение по инструкции ниже.
3. Выберите занятие в таблице. На лекции используйте слайды и конспект, на практике заполняйте ноутбук в папке work/ выбранного занятия.
4. Сохраняйте свои решения и отчёт в своей копии, затем делайте коммит. Отправлять решения в общий учебный репозиторий не нужно. Способ сдачи объявляет преподаватель.

Все команды установки и Git выполняются из **корня репозитория** — там, где этот README.md и requirements.txt.

## Подготовка окружения

Нужны Python 3.12 и Git. Первая пара использует pandas 2.2.2 и NumPy 1.26.4; исходный комплект проверен с Python 3.12.8. requirements.txt закрепляет прямые зависимости; транзитивные зависимости не зафиксированы полностью. Интернет нужен для установки, данные опубликованных занятий уже включены в репозиторий.

### macOS / Linux

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m ipykernel install --user --name hmda-lesson-01 --display-name "HMDA — занятие 1"
python -m jupyter lab
```

### Windows — PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m ipykernel install --user --name hmda-lesson-01 --display-name "HMDA — занятие 1"
.\.venv\Scripts\python.exe -m jupyter lab
```

В JupyterLab откройте **lessons/01-introduction/work/notebook.ipynb**, выберите ядро **HMDA — занятие 1**. Его рабочая папка должна оканчиваться на work/. Ноутбук использует относительный путь ../data: сохраняйте структуру папок.

### Последующие запуски

macOS / Linux:

```bash
source .venv/bin/activate
python -m jupyter lab
```

Windows:

```powershell
.\.venv\Scripts\python.exe -m jupyter lab
```

При изменении requirements.txt в следующих занятиях повторите установку зависимостей в том же окружении.

## Структура

```text
README.md                          Каталог опубликованных занятий и запуск
requirements.txt                   Общее окружение
.gitignore                         Исключения Git
lessons/
  01-introduction/
    README.md                      Порядок работы на первой паре
    lecture/                       Слайды, конспект, вопросы
    practice/guide.md               Условия практики
    practice/homework.md            Условия домашней работы
    work/notebook.ipynb             Практика
    work/README.md                  Отчёт практики
    work/homework.ipynb             Самостоятельная домашняя работа
    work/homework.md                Отчёт домашней работы
    data/                          Данные, словарь и происхождение
  02-data-quality/
    README.md                      Порядок работы второго занятия
    lecture/                       Слайды, конспект и демонстрация
    practice/                      Условия, домашняя и разбор практики
    work/                          Ноутбуки и шаблоны отчётов
    data/                          Оригинал и учебный экспорт
```

Каждое опубликованное занятие имеет свою папку и собственный маршрут работы. Данные хранятся внутри соответствующего блока, чтобы расчёты предыдущих занятий оставались воспроизводимыми.

## Получение новых материалов

Если скачивали ZIP — получите свежую копию отдельно и перенесите свои решения, сохраняя предыдущую копию.

Если клонировали репозиторий преподавателя напрямую, перед обновлением сохраните свою работу коммитом и выполните git pull. При конфликте сохраните оба варианта и обратитесь к преподавателю.

Если работаете через fork, используйте Sync fork на GitHub, затем git pull в своей локальной копии. Свои решения предварительно сохраните коммитом; конфликты нельзя разрешать удалением собственной работы вслепую.

## Материалы и источники

Первая пара использует реальные публичные ипотечные записи CFPB/FFIEC HMDA за 2023 год. Что означает HMDA, как определены показатели и какие есть ограничения, объясняется на [странице первого блока](lessons/01-introduction/README.md) и в его [карточке данных](lessons/01-introduction/data/card.md).

Публичные записи модифицированы издателем для защиты приватности. Происхождение, условия использования, параметры снимка и контрольные суммы хранятся рядом с данными. Лицензия на учебные тексты и слайды в исходном комплекте не задана; отдельная лицензия автоматически не назначается.
